# Carteles oficiales

Aquí van los carteles oficiales que las organizaciones envíen o autoricen.

1. Guarda la imagen con el identificador de la carrera: `media-maraton-ciudad-de-cadiz.jpg`
   (el mismo que aparece en la dirección de su ficha, por ejemplo `runiverso.com/cadiz/#media-maraton-ciudad-de-cadiz`).
2. Añade el nombre del archivo a `carteles/carteles.js` y a `CARTELES` en `tools/poster.py`.

Mientras no haya cartel oficial, la web muestra el cartel Runiverso generado automáticamente.
Formato recomendado: vertical 3:4 (por ejemplo 900 × 1200 px), JPG de menos de 300 KB.
