# Runiverso

**Calendario de carreras de running en España:** medias maratones, maratones, 10K y trail, con fechas, marcas de la última edición, calculadora de ritmo y el especial San Silvestre 2026.

🌐 Web: [runiverso.com](https://runiverso.com)
🎵 TikTok: [@runiverso_](https://www.tiktok.com/@runiverso_)
💬 WhatsApp: [canal Runiverso](https://whatsapp.com/channel/0029VbDrJk2InlqSVj746L0L)

---

Este repositorio es la fuente de runiverso.com: cada cambio que se sube a la rama `main` se publica automáticamente en Cloudflare Pages (proyecto `runiverso`).

| Ruta | Contenido |
|---|---|
| `index.html` | Portada con el calendario completo |
| `san-silvestre-2026/` | Especial San Silvestre 2026 y sus archivos de calendario `.ics` |
| `carreras/` | Ficha de cada carrera |
| `assets/` | Estilos compartidos (`runiverso.css` es el tema actual) |
| `favicon.svg` | Icono de Runiverso (monograma R) |
| `og.png` | Imagen para compartir en redes |
| `sitemap.xml`, `robots.txt` | Para buscadores |
